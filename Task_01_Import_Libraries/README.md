## Student Questions & Answers
- **What is Pandas used for?**  
  Used for working with tables and datasets (loading, inspecting, filtering, cleaning, and analyzing tabular data).
- **What is NumPy used for?**  
  Used for numerical operations and matrix manipulations, commonly used alongside Pandas.
- **What is Matplotlib used for?**  
  Used for creating, labeling, resizing, and displaying graphs and plots.
- **What is Seaborn used for?**  
  A statistical data visualization library built on top of Matplotlib for attractive statistical charts like heatmaps and boxplots.
